# AGENTS

Use `plumbeer-skill-creator` to create or update a skill in this repository.
When invoked, it will guide you through creating a new agent skill following Plumbeer's philosophy: grounded expertise, prescriptive instructions, validation gates, and clear patterns.

**Naming convention:** Every skill name must start with the `plumbeer-` prefix (e.g. `plumbeer-skill-backwards`, `plumbeer-pr-pitch`). Never create a skill whose `name` field or directory name omits the prefix.
